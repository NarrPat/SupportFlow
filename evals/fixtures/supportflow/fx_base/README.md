# FX-BASE · 首次迁移与重复 seed

`seed.json` 是为 SF-F01 / SF-T001 手工编写的确定性合成输入，客户名称、账号、订阅与授权关系均为虚构。客户在应用库，订阅在沙箱库，两侧通过稳定的 `tenant_id` 和 `customer_id` 对应。用户名只作登录标识，角色取自 `memberships`，可访问的客户逐条列在 `customer_scopes`。密码由本地部署侧提供。

两租户各有客服、主管、管理员。登录 `a_support` 时，其 scope 包含本租户的 `cus_a_01` 和 `cus_a_02`。同租户的 `cus_a_03` 与其他租户的客户均在该 scope 之外。三组客户编码在两个租户中成对复用。举例来说，按 `tenant_a` 和 `C-001` 定位应得到 `cus_a_01`；仅用 `C-001` 无法判断客户。

订阅的席位数和业务版本是初始值，第二次 seed 需保留已存在的业务状态。邀请、历史 grant 和知识资料随对应专用 fixture 提供。SF-T001 的数据库快照、跨库写尝试和独立断言由集成测试采集，运行结果存放在对应证据批次。
